พลาดแล้วหายไหม เดินเรื่องตามลำดับเล่น บอส Isaaru บอส Evrae Altana บอส Seymour Natus มอนสเตอร์ ศัพท์ควรรู้
เนื้อเรื่อง: ศาสนจักร Yevon ที่ Yuna รับใช้มาทั้งชีวิตเพิ่งตัดสิน ประหารชีวิต เธอและเหล่าผู้พิทักษ์ในฐานะคนนอกรีต — คำทรยศที่สมบูรณ์แบบที่สุด เมื่อกลไกพื้นเปิดออก ทุกคนถูกโยนดิ่งลงสู่ Via Purifico เขาวงกตใต้เมือง Bevelle ที่ใช้ "ชำระล้าง" นักโทษด้วยการปล่อยให้ตายในความมืด ทีมถูกแยกจากกันใต้ดิน ต่างคนต่างต้องเอาชีวิตรอดตามลำพังแล้วหาทางกลับมาพบกันให้ได้ กลุ่มของ Yuna เดินบนเส้นทางแห้ง ต้องดวลกับซัมมอนเนอร์ Isaaru — คู่แข่งที่ยังศรัทธา Yevon อย่างบริสุทธิ์ใจ ส่วนกลุ่มของ Tidus ต้องดำผ่านเขาวงกตใต้น้ำและเผชิญ Evrae Altana ซากอมตะของมังกรเฝ้าเมืองที่เคยสู้กันบนเรือบิน ทุกก้าวในความมืดนี้ ความศรัทธาของ Yuna ที่มีต่อ Yevon ค่อย ๆ แตกร้าวลงทีละน้อย

❗ พลาดแล้วหายถาวรไหม?

ระวังของหายถาวร (เส้นทางใต้น้ำของ Tidus): ในเขาวงกตใต้น้ำมี Trigger Command สำหรับปลดล็อกประตูลัด อยู่ ถ้ากดใช้เพื่อเปิดทางออกเร็ว ประตูที่กั้นหีบ Rematch (อาวุธ Wakka) กับ Avenger (อาวุธ Tidus) จะปิดตายและเก็บไม่ได้อีก — ว่ายไปเปิดหีบทั้งสองก่อน แล้วค่อยหาทางออกเอง อย่าพึ่ง Trigger Command
เก็บให้ครบตั้งแต่รอบแรก: หีบบนเส้นทางแห้งของ Yuna (Mega-Potion, Wht/Blk Magic Sphere, Elixir, Skill Sphere, Lucid Ring, 10,000 Gil) และอาวุธใต้น้ำสองชิ้น เป็นของที่กลับมาเก็บยากภายหลัง เพราะ Via Purifico ปิดเป็นด่านผ่านครั้งเดียวในเนื้อเรื่อง
ด่านนี้คือสวิตช์เปิด Dark Aeon (ฉบับ HD Remaster ที่คุณเล่น): Dark Aeon ทั้ง 8 ตัวจะเริ่มไปยืนประจำจุดทั่ว Spira ทันทีที่ทีมหนีพ้น Bevelle และจบ Via Purifico — นับจากด่านนี้เป็นต้นไป พื้นที่อย่าง Besaid Village, Lake Macalania, Thunder Plains, Mt. Gagazet และโดม Zanarkand จะมีตัวขวางที่แข็งเกินกำลังทีมตอนนี้มาก อย่าเพิ่งย้อนกลับไปเก็บของเก่าโดยไม่เช็กก่อน (รายชื่อและตำแหน่งครบอยู่ในกล่อง Dark Aeon ของด่าน 22) — ฉบับ PS2 ดั้งเดิมของอเมริกาเหนือไม่มี Dark Aeon เลย

▶ เดินเรื่องตามลำดับเล่น 0/0

💬 ก่อนเริ่ม: ทีมถูกแบ่งเป็นสองกลุ่มอัตโนมัติตามความสามารถในการดำน้ำ — กลุ่มบก คือ Yuna (ออกเดินคนเดียวก่อน แล้วค่อยเจอ Auron, Kimahri, Lulu กลางทาง) เดินเส้นทางแห้ง ต้องดวลกับ Isaaru ส่วน กลุ่มน้ำ คือสามนักว่ายจากสนามบลิตซ์บอล (Tidus, Wakka, Rikku) ต้องดำผ่านท่อน้ำไปเจอ Evrae Altana — จำสลับกันไม่ได้เด็ดขาด เพราะสมาชิกที่ใช้สู้แต่ละฝั่งต่างกันโดยสิ้นเชิง (ฝั่ง Tidus ไม่มี Yuna จึงไม่มี Aeon) ทั้งสองด่านเล่นต่อเนื่องกันก่อนจะไปรวมพลที่ Highbridge

1🟣 กลุ่มของ Yuna — เส้นทาง "บก" (ดวล Isaaru)

💬 บรรยากาศตอนนี้: Yuna เดินคนเดียวในความมืดชื้น ก่อนจะได้พบผู้พิทักษ์คนอื่นกลางทาง ปลายเขาวงกตมี Isaaru ซัมมอนเนอร์หนุ่มผู้เคยฝันอยากปราบ Sin เหมือนกัน ยืนขวางอยู่ เขาไม่ได้เกลียด Yuna — ตรงกันข้าม เขายกย่องเธอ แต่ในเมื่อ Yevon สั่งมา เขาก็จะทำหน้าที่ "ส่ง" เธอด้วยมือของ Aeon ตัวเอง การดวลครั้งนี้จึงเต็มไปด้วยความเคารพและความเศร้า — ซัมมอนเนอร์สองคนที่ศรัทธาสิ่งเดียวกัน กลับต้องเล็งอสูรใส่กัน เพราะศาสนจักรที่บิดเบี้ยว
  1. คุม Yuna เดินหาทางออกในเขาวงกตแห้ง กวาดหีบให้ครบทั้ง 7 ใบตามช่องติ๊กด้านล่าง — มีทั้ง Elixir, Wht/Blk Magic Sphere, Skill Sphere, Lucid Ring และเงิน 10,000 Gil
  2. เมื่อผู้พิทักษ์กลับมารวมกลุ่มแล้ว เดินต่อไปสุดทางจะเจอ Save Sphere ก่อนถึง Isaaru — แตะเซฟ เติม HP/MP ให้เต็ม แล้วค่อยเดินเข้าไปคุย
  3. ดวลกับ Isaaru — ทีมนี้มี Lulu (เวท) กับ Auron/Kimahri (กายภาพแรง) หนุน Aeon ของ Yuna อยู่ด้วย เตรียม MP ของ Yuna ให้พร้อม (ดูบล็อกบอสถัดจากนี้)
  4. ชนะแล้ว Isaaru ยอมรับความพ่ายแพ้อย่างสง่างาม เปิดทางให้ Yuna เดินต่อขึ้นสู่ Highbridge

เก็บของในฉากนี้

  • Wht Magic Sphere — หีบบนเส้นทางบกของ Yuna

Isaaru Grothia 8,000 – Pterya 12,000 – Spathi 20,000 (กลุ่ม Yuna – เส้นทางบก)

ทำไมต้องสู้: Isaaru เชื่อใน Yevon อย่างสุดหัวใจ เมื่อศาสนจักรสั่งประหาร Yuna เขาจึงรับหน้าที่ดวลด้วยความเคารพ ไม่ใช่ความแค้น — ซัมมอนเนอร์สองคนที่ฝันเดียวกัน แต่ถูกบังคับให้เล็งอสูรใส่กัน

ทีมนี้มี Auron, Kimahri, Lulu ร่วมด้วย ใช้ตีกายภาพหรือเวทของ Lulu สลับกับ Aeon ของ Yuna เอง ได้เต็มที่ ไม่ต้องพึ่ง Aeon อย่างเดียว Isaaru เรียก Aeon ออกมาไล่ทีละตัว: Grothia (ร่างพิมพ์เดียวกับ Ifrit – ท่า Fira, Hellfire) – Pterya (ร่างพิมพ์เดียวกับ Valefor – ท่า Sonic Wings ที่ถ่วงคิว และ Energy Ray) เป็นตัวบิน กายภาพประชิดพลาดง่าย ใช้ Aeon ตีสวนหรือเวทของ Lulu แทน – Spathi (ร่างพิมพ์เดียวกับ Bahamut) แข็งสุดและมี Mega Flare เป็นท่าเดียวที่ทำดาเมจจริงจัง ให้ยก Shell/Protect หรือส่ง Aeon มารับหมัดนั้นแทนคน แล้วรุมตีให้จบก่อนเกจ Overdrive มันเต็มรอบสอง

ข้อควรรู้เรื่องธาตุ: Aeon ทั้งสามของ Isaaru ไม่มีจุดอ่อนธาตุที่ตายตัว และกันสถานะเกือบทุกอย่าง — จึงอย่าคาดหวังว่าธาตุตรงข้ามจะทำดาเมจสองเท่า วิธีที่ได้ผลจริงคือ อัดดาเมจก้อนใหญ่ต่อเนื่อง (Overdrive ของ Aeon เรา + กายภาพแรง) ให้จบทีละตัวเร็วที่สุด แต่เลี่ยงยิงเวทไฟใส่ Grothia ไว้ก่อนจะปลอดภัยกว่า เพราะร่างสาย Ifrit กินไฟไม่เจ็บ

Steal / Drop: ไม่มีทั้งคู่ — เป็นการดวล Aeon ต่อ Aeon ที่ให้ AP เพียง 1 หน่วยต่อตัว (ยืนยันแล้ว) เก็บ MP และ Overdrive ของ Aeon ไว้ให้พอครบสามยกจะคุ้มกว่ามาก

2🔵 กลุ่มของ Tidus — เส้นทาง "ใต้น้ำ" (สู้ Evrae Altana)

💬 บรรยากาศตอนนี้: Tidus, Wakka และ Rikku ดำดิ่งในท่อน้ำมืดมิด อากาศมีจำกัดในใจแม้เกมจะไม่จับเวลา ความกดดันคือการหาทางออกให้เจอก่อนจะหลงวน แล้วที่ก้นเขาวงกต ซากบางอย่างก็ลอยเข้ามา — Evrae Altana มังกรเฝ้าประตู Bevelle ตัวเดิมที่เคยสู้กันบนเรือบิน บัดนี้ตายแล้วแต่ไม่ถูก "ส่ง" กลายเป็นซากเน่าอมตะที่ยังขยับ กลิ่นของความตายและความล้มเหลวของ Yevon ลอยคลุ้งไปทั้งใต้น้ำ
  1. คุม Tidus ว่ายผ่านเขาวงกตใต้น้ำ — ว่ายไปเปิดหีบ Rematch และ Avenger ก่อนเป็นอันดับแรก อย่าเผลอใช้ Trigger Command ปลดล็อกประตู ไม่งั้นเสียหีบถาวร
  2. ก่อนถึงจุดสู้จะมี Save Sphere ให้แตะเซฟ — ทีมนี้ ไม่มี Yuna จึงไม่มี Aeon และไม่มี Lulu คอยร่ายเวทให้ พกไอเทมฟื้นฟูไปให้พอ
  3. สู้กับ Evrae Altana — จำไว้ว่ามันเป็น undead ให้ใช้ไอเทมฟื้นฟูเป็นอาวุธ (ดูบล็อกบอสถัดจากนี้)
  4. ผ่านแล้วว่ายขึ้นสู่ผิวน้ำไปสมทบกับกลุ่มของ Yuna ที่ Highbridge — ทีมกลับมารวมกันอีกครั้ง

เก็บของในฉากนี้

  • ⚠️ Rematch (อาวุธ Wakka) — หีบใต้น้ำ อย่าใช้ Trigger Command ปลดล็อกประตู!
  • ⚠️ Avenger (อาวุธ Tidus) — หีบใต้น้ำ อย่าใช้ Trigger Command ปลดล็อกประตู!
ย้ำอีกครั้ง: ถ้าใช้ Trigger Command เปิดประตูลัดเพื่อออกจากเขาวงกตเร็ว ๆ หีบ Rematch และ Avenger จะหายถาวร ให้ว่ายไปเปิดหีบทั้งสองด้วยตัวเองก่อนเสมอ

เตรียมตัวก่อนสู้

  • ตุน Phoenix Down และ X-Potion ไปให้เยอะก่อนดำลง — บอสตัวนี้เป็น undead ของฟื้นฟูจึงกลายเป็น "อาวุธ" หลักของศึก ราวสองครั้งก็จบ
  • เกราะติด Stone Ward / Stoneproof หรือ Ribbon — ท่า Stone Gaze ทำหินทีละคน ถ้ากันได้จะไม่มีอะไรน่ากลัวเหลือเลย ถ้าไม่มีก็พก Soft ไปแก้
  • จำไว้ว่าทีมนี้ไม่มี Yuna และไม่มี Lulu — ไม่มี Aeon ไว้บังและไม่มีเวทฮีลของ Lulu ต้องพึ่งไอเทมล้วน ๆ
  • ให้ Rikku เตรียม Steal ไว้เก็บของ และ Wakka ไว้ขว้างเสริมดาเมจ

Evrae Altana HP 16,384 (Overkill 2,000) (กลุ่ม Tidus – เส้นทางใต้น้ำ)

ทำไมต้องสู้: คือ Evrae มังกรเฝ้าเมือง Bevelle ตัวเดิมจากเรือบิน บัดนี้ตายแล้วแต่ไม่ถูกส่ง กลายเป็นซากอมตะเน่าเปื่อย — ภาพสะท้อนความล้มเหลวและความเน่าในของ Yevon ได้ชัดที่สุด

ทีมนี้มีแค่ Tidus, Wakka, Rikku — ไม่มี Yuna จึงไม่มี Aeon และไม่มี Lulu ที่ร่ายเวทได้ ต้องสู้ด้วยกายภาพ + ไอเทมเป็นหลัก มันเป็น undead (ซากอมตะ) — ทุกอย่างที่ควรจะรักษา กลับทำให้มันเจ็บ! ขว้าง Phoenix Down หรือ X-Potion ใส่มัน ราวสองครั้งก็ปิดจ๊อบได้ เพราะเกราะกายภาพและเกราะเวทของมันต่ำมาก (Def/MDef เท่ากับ 1 ทั้งคู่)

ท่าที่ต้องระวัง: Stone Gaze ทำ Petrify (หิน) ใส่ทีละคน — ใส่เกราะที่มี Stone Ward/Stoneproof หรือ Ribbon จะตัดปัญหานี้ทิ้งได้เลย, Photon Spray ยิงกวาดทั้งทีม, และกรงเล็บตีเดี่ยวธรรมดา ระหว่างนี้ให้ Wakka ขว้างเสริมและ Rikku ขโมยของ

Steal: Water Gem (rare: Healing Spring) – Drop: อาวุธ/เกราะแบบสุ่ม (ไม่ใช่ของตายตัว) – AP: 5,800 (Overkill 8,700)

3⚔️ รวมพลที่ Highbridge — Seymour Natus ขวางทาง

💬 บรรยากาศตอนนี้: เพิ่งจะได้หายใจโล่งที่ทุกคนปลอดภัย Seymour ก็ปรากฏตัวอีกครั้ง คราวนี้ในสภาพวิญญาณที่ตายแล้วแต่ปฏิเสธจะถูกส่ง หมกมุ่นกับความตายจนกลายเป็นภัยต่อทั้ง Spira เขาเรียกร่าง Natus พร้อม Mortibody คอยดูดพลัง — บททดสอบสุดท้ายก่อนทีมจะได้หนีออกจากเงื้อมมือ Yevon จริง ๆ
  1. ทั้งสองกลุ่มมาบรรจบกันที่ Highbridge — สลับตัวละครในทีมได้อิสระอีกครั้ง (Aeon และเวทของ Lulu กลับมาใช้ได้เต็มทีม) จะมี Save Sphere ให้เซฟและจัดของก่อนเจอ Seymour
  2. สู้กับ Seymour Natus + Mortibody (ดูบล็อกบอสถัดจากนี้)
  3. ชนะแล้วทีมหนีขึ้นเรือบิน Fahrenheit ออกจาก Bevelle ได้สำเร็จ — จบด่าน Via Purifico

Seymour Natus HP 36,000 + Mortibody 4,000 (Highbridge – รวมพล)

ทำไมต้องสู้: Seymour ที่ตายแล้วยังไม่ยอมถูกส่ง หมกมุ่นกับความตายจนเป็นภัยต่อทั้งโลก ขวางทางหนีของทีมเป็นด่านสุดท้ายก่อนพ้น Bevelle

ทีมกลับมาครบแล้ว เลือกตัวได้อิสระทั้งเจ็ดคนรวม Aeon ของ Yuna — ตี Seymour ตัวหลักตรง ๆ เพื่อดันเปลี่ยนเฟส (อย่าเสียเวลากับ Mortibody ก่อน) – วาง Reflect ไว้ที่ Seymour เพื่อสะท้อนเวทที่มันร่าย รวมทั้ง Cura ที่มันใช้ฮีลตัวเอง กลับมาเข้าทีมเราแทน – ระวัง Flare ในเฟสท้ายที่แรงมาก เตรียมฮีลเต็มก่อนเข้าช่วงนั้น และระวัง Break ที่ทำหินใส่คนของเรา

กลไก Mortibody ที่ควรใช้ให้เป็นประโยชน์: Mortibody ใช้ Desperado ปัดบัฟของทีมทิ้ง และเมื่อถูก KO มันจะฟื้นตัวเองด้วย Mortibsorption โดย ดูด HP จากตัว Seymour เอง — ครั้งแรกดูดไป 4,000 แล้วลดลงครั้งละ 1,000 จนคงที่ที่ 1,000 แปลว่าการทุบ Mortibody ให้ล้มซ้ำ ๆ คือการให้มันช่วยเราตัด HP ของ Seymour ไปในตัว เป็นทางลัดที่ปลอดภัยถ้าทีมยังตีไม่แรงพอ

Steal (จาก Seymour): Tetra Elemental – Drop: อาวุธ/เกราะแบบสุ่ม – Mortibody: ไม่มีของดรอป

📖 ศัพท์ควรรู้ (สำหรับคนห่างเกมนาน)

Aeon
อสูรศักดิ์สิทธิ์ที่ซัมมอนเนอร์เรียกออกมาสู้แทนทีม ระหว่างที่ Aeon อยู่ในสนาม มันรับดาเมจแทนทุกคน ถ้ามันล้มก็แค่หายไป คนในทีมไม่เจ็บ
undead (ซากอมตะ)
ศัตรูประเภทที่ "กลับด้าน" กับการรักษา — ยา Potion, เวทฮีล และ Phoenix Down กลายเป็นดาเมจใส่มัน ส่วนเวทที่ฆ่าทันทีจะไม่ทำงาน
Petrify (หิน) / Stone Ward / Stoneproof
Petrify คือสถานะกลายเป็นหิน ขยับไม่ได้ และถ้าโดนตีซ้ำจะแตกเป็นผงตายถาวรในศึกนั้น ส่วน Stone Ward (กันบางส่วน) และ Stoneproof (กัน 100%) คืออบิลิตี้ที่ใส่ไว้บนเกราะเพื่อป้องกัน
Trigger Command
คำสั่งพิเศษที่โผล่เฉพาะบางฉาก แทนที่คำสั่งปกติชั่วคราว ในด่านนี้มันใช้เปิดประตูลัดใต้น้ำ — ซึ่งไม่ควรกด เพราะจะปิดทางเข้าหีบสองใบถาวร
Overdrive
ท่าไม้ตายประจำตัวละครหรือ Aeon เกจจะเต็มเมื่อโดนตีหรือทำดาเมจสะสมมากพอ ปล่อยแล้วเกจรีเซ็ต
Overkill
การฆ่าศัตรูด้วยดาเมจครั้งสุดท้ายที่เกินเกณฑ์ที่กำหนด จะได้ AP และไอเทมดรอปเพิ่มขึ้น ตัวเลขในวงเล็บหลัง HP คือเกณฑ์นั้น
Steal / Drop
Steal คือคำสั่งขโมยของจากศัตรูระหว่างสู้ (ได้ครั้งเดียวต่อบอสหนึ่งตัว) ส่วน Drop คือของที่ตกให้เมื่อเราฆ่ามัน — คนละช่องกัน เก็บได้ทั้งสองอย่างในศึกเดียว
rare (ของหายาก)
ช่องของที่ขโมย/ดรอปได้แบบสุ่มโอกาสต่ำ ถ้าไม่ออกจะได้ของธรรมดาแทน
Reflect
เวทที่สร้างกำแพงสะท้อน — เวทที่ยิงใส่เป้าหมายที่ติด Reflect จะเด้งกลับไปหาฝั่งตรงข้ามแทน ใช้กับศัตรูที่ชอบฮีลตัวเองได้ผลมาก
Shell / Protect
Shell ลดดาเมจจากเวทที่ได้รับ ส่วน Protect ลดดาเมจจากการตีกายภาพ ทั้งคู่ลดลงราวครึ่งหนึ่ง
Armor Break / Piercing
Armor Break คือท่าที่ลดค่าเกราะกายภาพของศัตรูชั่วคราว ส่วน Piercing คืออบิลิตี้บนอาวุธที่ทะลุเกราะไปเลย (Auron และ Kimahri มีติดตัวอยู่แล้วในหลายอาวุธ)
Save Sphere
ทรงกลมเรืองแสงตามทาง แตะเพื่อบันทึกเกมและฟื้น HP/MP เต็ม มักวางไว้ก่อนบอสเสมอ
Unsent (วิญญาณค้าง)
คนตายที่ยังไม่ถูกพิธี Sending ส่งไป Farplane จึงยังเดินอยู่ในโลกได้เหมือนคนเป็น — Seymour ในด่านนี้คือหนึ่งในนั้น
Dark Aeon
Aeon ร่างมืดพลังมหาศาลที่เพิ่มเข้ามาในฉบับ International และมีอยู่ใน HD Remaster ที่คุณเล่น มี 8 ตัวยืนขวางตามพื้นที่ต่าง ๆ หลังจบด่านนี้ — แข็งกว่าบอสเนื้อเรื่องหลายสิบเท่า
Highbridge
สะพานยาวเชื่อมเมือง Bevelle กับที่ราบด้านนอก เป็นจุดที่ทั้งสองกลุ่มกลับมาเจอกันหลังหนีออกจาก Via Purifico
